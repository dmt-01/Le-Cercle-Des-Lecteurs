Voici tout ce que tu dois maîtriser pour ton CDA :

BLOC 1 — Concevoir et développer des composants d'interface utilisateur


Pratique

Tests d'interface (Jest, Cypress)


BLOC 2 — Concevoir et développer la persistance des données

Théorie

Algèbre relationnelle
Normalisation des BDD (1NF, 2NF, 3NF)
Transactions ACID
Indexation et optimisation des requêtes
RGPD et sécurité des données

Pratique

SQL (DDL, DML, DCL)
PostgreSQL ou MySQL
ORM (Prisma, TypeORM, Doctrine, Hibernate)
Migrations de base de données
Requêtes complexes (jointures, sous-requêtes, agrégats)
Sauvegardes et restauration


BLOC 3 — Concevoir et développer une application multicouche

Théorie

Architecture MVC
Architecture trois tiers (Frontend / Backend / BDD)
API REST (méthodes HTTP, codes de statut, conventions)
Authentification et autorisation (JWT, OAuth2, sessions)
Sécurité applicative (OWASP Top 10, XSS, CSRF, injections SQL)
Design patterns (Singleton, Factory, Repository, etc.)
Diagrammes UML (use case, classes, séquence, activité)

Pratique

Développement backend (Express, Symfony, Spring, etc.)
Création et consommation d'API REST
Gestion des rôles et permissions
Middleware et intercepteurs
Gestion des erreurs et logs
Tests unitaires et d'intégration (Jest, PHPUnit, JUnit)
Documentation API (Swagger / OpenAPI)


BLOC 4 — Gestion de projet et travail en équipe

Théorie

Méthodes agiles (Scrum, Kanban)
Cycle de vie d'un projet (V, agile, RAD)
Cahier des charges fonctionnel et technique
Veille technologique
Gestion de version Git (branches, merge, rebase, pull requests)
Dossier de projet CDA (structure et contenu)

Pratique

Git et GitHub / GitLab
Trello, Jira ou équivalent
Rédaction de documentation technique
Manuel utilisateur
Plan de tests fonctionnels
Recette et validation


BLOC 5 — Déploiement et infrastructure

Théorie

Conteneurisation (Docker, Docker Compose)
CI/CD (intégration et déploiement continus)
Hébergement (VPS, cloud, serveurs mutualisés)
Variables d'environnement et sécurisation des configs
HTTPS et certificats SSL

Pratique

Dockerfile et docker-compose.yml
Déploiement sur un serveur (OVH, DigitalOcean, AWS, etc.)
Configuration Nginx ou Apache
GitHub Actions ou GitLab CI
Monitoring basique (logs, uptime)


Pour la soutenance CDA tu dois présenter

Le contexte et les besoins du projet
Les choix techniques justifiés
Le MCD / MLD commenté
Les maquettes (zoning + wireframe + mockup)
Les user stories et use cases
L'architecture de l'application
Une démonstration fonctionnelle
Le dossier de projet complet
Un retour critique sur le projet (difficultés, améliorations)


Les notions transversales à connaître

Les types de données (primitifs, objets, tableaux)
La programmation orientée objet (encapsulation, héritage, polymorphisme, abstraction)
La programmation asynchrone (Promises, async/await, callbacks)
Les algorithmes de base (tri, recherche, récursivité)
La complexité algorithmique (O(n), O(log n), etc.)
Les protocoles réseau (HTTP, HTTPS, TCP/IP, DNS)
La gestion des exceptions et erreurs
